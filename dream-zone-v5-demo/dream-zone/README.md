# DREAM ZONE — сайт учебного центра

Next.js 15 (App Router) · React 19 · TypeScript · Tailwind CSS 4 · Framer Motion · React Hook Form + Zod.
Языки: RU (по умолчанию), UZ (латиница), EN. Маршруты: `/ru`, `/uz`, `/en`.

> **Статус:** код написан, но в среде разработки не было доступа к npm, поэтому
> `npm install`, `npm run build` и `npm run typecheck` ещё **ни разу не запускались**.
> Первым делом выполните их и исправьте возможные ошибки. Форма не проверена на реальной отправке.

## Запуск

```bash
npm install
cp .env.example .env.local   # заполните переменные
npm run typecheck
npm run dev                  # http://localhost:3000
npm run build && npm start
```

## Где что менять

| Что | Где |
| --- | --- |
| Название, логотип, контакты, hero-фото | `src/config/brand.ts` |
| Цвета, шрифты, радиусы | `src/app/globals.css` (блок `@theme`) |
| Курсы | `src/data/courses.ts` (`confirmed: false` — направление не подтверждено) |
| Новые группы | `src/data/groups.ts` (группы с прошедшей датой скрываются сами) |
| Преподаватели, отзывы, галерея | `src/data/teachers.ts`, `reviews.ts`, `gallery.ts` |
| Тексты интерфейса и FAQ | `src/i18n/dictionaries/{ru,uz,en}.ts` |
| Форма и обработчик | `src/components/ContactForm.tsx`, `src/app/api/lead/route.ts` |

Пустые разделы показывают аккуратное состояние «материалы обновляются», а не выдуманные данные.
Узбекский перевод нужно проверить у носителя языка.

## Заявки в Telegram

1. Создайте бота у @BotFather, получите токен.
2. Добавьте бота в чат администратора, узнайте chat ID.
3. Запишите `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` в `.env.local` (локально) и в переменные окружения хостинга.

Пока переменных нет, форма отвечает «приём заявок не подключён» и предлагает позвонить. Заявки нигде не хранятся.
Защита: honeypot, серверная валидация Zod, лимит 5 заявок за 10 минут с IP (в памяти процесса; на serverless
для надёжности нужен внешний лимитер).

## Деплой и домен

Подходит Vercel: импортируйте репозиторий, задайте `NEXT_PUBLIC_SITE_URL` (боевой домен) и переменные Telegram,
затем подключите домен в Settings → Domains. Включится HTTPS.

## Что нужно получить от DREAM ZONE

- Оригинальный логотип (SVG/PNG, прозрачный фон) и точный фирменный синий.
- Адрес, геолокация, график работы, подтверждённые телефоны.
- Окончательный список курсов; подтверждение Turkish и шахмат.
- Описания курсов, уровни, формат, длительность, цены (если публиковать).
- Список открытых групп: курс, преподаватель, дни/время, дата старта.
- Реальные фото центра, занятий, преподавателей (с правом публикации).
- Имена, специализации и подтверждённые биографии преподавателей.
- Настоящие отзывы и результаты с разрешением на публикацию.
- Канал заявок (Telegram или email), финальные переводы, разрешение на использование бренда.

## Перед передачей клиенту

Собрать проект без ошибок, проверить все маршруты на трёх языках, отправить тестовую заявку, пройти сайт на телефоне,
заменить заглушку hero-фото, убрать записи с `demo: true`, заполнить контакты.

## Демо-версия (для показа администратору)

- Фото на главной, в галерее, у преподавателей и в «Результатах» — стоковые снимки Pexels
  (бесплатная лицензия, указание автора не требуется: https://www.pexels.com/license/).
  Все помечены «Демо». Адреса картинок собраны в `src/lib/photos.ts`, `src/data/gallery.ts`,
  `src/data/teachers.ts`, `src/data/results.ts`, `src/config/brand.ts`.
- Преподаватели безымянные («Преподаватель 1…»), без выдуманных биографий. В «Результатах» нет баллов и отзывов.
- Телефон и Telegram размыты до клика (`src/components/Spoiler.tsx`). Это визуальное размытие: текст остаётся в коде страницы.
- Перед публикацией: заменить фото своими (положить в `public/images`, поправить пути), убрать `demo: true`,
  убрать размытие (заменить `<Spoiler>` обычной ссылкой), удалить `src/lib/diag.ts` и его вызовы в `layout.tsx` и страницах.
